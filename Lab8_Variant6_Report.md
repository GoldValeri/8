## 2. Описание задачи и алгоритмов

### 2.1. Bin packing

Даны предметы размеров $s_1,\ldots,s_n$ и контейнеры вместимости $C$.  
Минимизировать число контейнеров, не превышая $C$ в каждом.

**Нижняя оценка:** $LB = \lceil\sum s_i / C\rceil$. Оптимум $\ge LB$.

### 2.2. First Fit (FF)

Каждый предмет — в *первый* контейнер, куда он помещается; иначе — новый.

### 2.3. Best Fit (BF)

Каждый предмет — в контейнер с *наименьшим остатком* среди подходящих.

### 2.4. FFD и Improved (Ж6)

FFD: сортировка по убыванию + FF.  
Improved = $\min(\mathrm{FF},\,\mathrm{BF},\,\mathrm{FFD})$.

---

## 3. Контрпример

Предметы $[2, 2, 2, 2, 3, 3]$, $C = 5$.

| Алгоритм | Контейнеров |
|---|---:|
| First Fit | **4** |
| Best Fit | **4** |
| FFD | 3 |
| Оптимум | **3** — $(2+3),\ (2+3),\ (2+2)$ |
| LB | 3 |

Отклонение FF/BF от оптимума: **33,3 %**.  
Причина: без предварительной сортировки мелкие предметы «закрывают» контейнеры, оставляя крупные без пары.

## 4. Листинг (с пояснениями)

Полный код: `lab8-variant6/main.py`.

```python
def first_fit(sizes, capacity):
    bins = []                         # остатки вместимости
    for s in sizes:
        placed = False
        for i, rem in enumerate(bins):
            if rem >= s:              # первый подходящий
                bins[i] -= s
                placed = True
                break
        if not placed:
            bins.append(capacity - s) # новый контейнер
    return len(bins)

def best_fit(sizes, capacity):
    bins = []
    for s in sizes:
        best_i, best_rem = -1, capacity + 1
        for i, rem in enumerate(bins):
            if s <= rem < best_rem:   # минимальный остаток
                best_i, best_rem = i, rem
        if best_i >= 0:
            bins[best_i] -= s
        else:
            bins.append(capacity - s)
    return len(bins)

def first_fit_decreasing(sizes, capacity):
    return first_fit(sorted(sizes, reverse=True), capacity)

def improved_greedy(sizes, capacity):  # Ж6
    return min(first_fit(sizes, capacity),
               best_fit(sizes, capacity),
               first_fit_decreasing(sizes, capacity))
```

## 6. Выводы

1. First Fit и Best Fit — быстрые $O(n\cdot B)$ эвристики; среднее превышение над LB 3–3,5 %.
2. Контрпример показывает: без сортировки жадность может дать на 33 % больше контейнеров.
3. FFD (убывающая сортировка + FF) резко улучшает качество: excess 0,36 %, совпадение с LB в 89 % случаев.
4. **Ж6:** Improved = min(FF, BF, FFD) наследует качество FFD.
5. Точный bin packing NP-труден; при $n=100$ эталоном служит нижняя оценка LB.
6. На практике: сортировать по убыванию (FFD) — простое и эффективное улучшение жадной упаковки.
